AdMob 광고와 개인정보 선택

무료 이용 시 Google AdMob 배너 광고가 표시될 수 있습니다. Google Mobile Ads SDK는 광고 제공·측정과 부정행위 방지를 위해 IP 주소, 앱·광고 이용 정보, 성능·진단 정보, 광고 ID·앱 세트 ID를 수집·공유할 수 있습니다. 해당되는 경우 기기에 로그인한 계정 관련 식별자도 처리합니다. IP 주소는 대략적인 위치를 추정하는 데 사용될 수 있습니다. 자세한 항목은 Google의 SDK 데이터 안내를 참고하시기 바랍니다.

Google User Messaging Platform(UMP)을 사용해 동의 상태를 확인하고 필요한 경우 개인정보 선택 양식을 표시합니다. SDK가 개인정보 선택 항목을 요구하는 경우 우측 메뉴에 ‘광고 개인정보 설정’이 나타납니다. 제공되는 선택은 해당 양식에서 변경할 수 있으며, 광고 ID 관련 설정은 Android의 광고 설정에서도 관리할 수 있습니다.

광고 제거 구매 권한이 확인된 경우 새로운 배너 광고 요청을 하지 않고 광고 영역을 제거합니다. 알람·약 복용 확인 화면에도 배너를 표시하지 않습니다. 광고 제거 구매가 Google에 이미 보관된 데이터를 삭제하는 것은 아닙니다.

보관 기간, 백업과 삭제 방법

복약 설정은 사용자가 수정하거나 삭제할 때까지 기기에 보관합니다. 복용 상태 값은 다음 복용 구간의 표시 판단에 사용되며, 저장된 값 자체가 그 시각에 자동 삭제되는 것은 아닙니다. 구매 영수증 사본은 광고 제거 권한 확인에 사용되며, 앱 데이터 삭제 또는 이후 정상 구매 조회에서 권한이 없는 것으로 확인되는 경우 제거됩니다.

  1. 약 하나 삭제: 해당 약의 확인창에서 ‘설정’을 열고 삭제를 선택해 확인합니다. 저장된 해당 약 정보와 복용 상태가 삭제되고 그 약의 예약 알림이 취소됩니다.
  2. 기기 내 앱 데이터 전체 삭제: Android 설정에서 약먹자 → 저장공간 → 데이터 삭제를 사용하거나 앱을 삭제합니다. 기기에 저장된 복약 정보·설정·영수증 사본이 제거됩니다. 메뉴 이름은 기기에 따라 다를 수 있습니다.
  3. Google 보유 정보: 앱 삭제만으로 Google의 구매 내역·광고 관련 정보·시스템 백업까지 삭제되지는 않습니다. 해당 서비스와 기기의 계정·백업·개인정보 설정을 이용해 관리해야 합니다.

앱은 Android 백업 및 기기 이전을 허용합니다. 따라서 기기·운영체제·사용자 설정에 따라 일부 앱 데이터가 시스템 백업이나 기기 이전에 포함될 수 있습니다. JTJ가 제공하는 별도의 클라우드 동기화는 없습니다. 구매 영수증 사본과 사용법 완료 표식은 백업 제외 저장소에 둡니다. 백업의 생성·복원·삭제 여부와 기간은 Android 및 백업 제공자의 설정에 따르며 JTJ가 원격으로 삭제하지 못합니다.
